# Kingfisher 1.0.41

Datum: 2026-11-02

- Gedächtnispflege: Ein ausdrücklich ausgewählter offener Aufgabenvorschlag kann mit korrigiertem Titel als weiterhin unbestätigter Nachfolger gespeichert werden. Originaltext, Herkunft und bisherige Fassung bleiben erhalten.
- Bereits bestätigte oder verworfene Vorschläge werden nicht umgeschrieben. Veränderte Quellen und konkurrierende Änderungen blockieren eine veraltete Korrektur.
- Wiederholte Korrekturaufrufe erzeugen keine doppelten Vorschläge oder Aufgaben. Die Änderung hinterlässt einen Verlaufseintrag ohne Mailtext.
- Diese Fassung erweitert die gezielte Wartungsschnittstelle. Sie startet keine automatische Neuprüfung und setzt den pausierten Großimport nicht fort.

App mindestens: 1.0.36
