# Kingfisher 1.0.43

Datum: 2026-11-03

- Eine ausdrücklich ausgewählte Originalquelle lässt sich lokal mit Qwen9B prüfen. Bestätigte passende Abläufe werden einbezogen; das Ergebnis bleibt ein Entwurf mit den tatsächlich gelesenen Belegen.
- Die optionalen lokalen Werkzeuge werden unter „Einstellungen → Für Techniker“ eingerichtet. Dafür werden nur öffentliche Laufzeitdateien geladen. Der getrennte Agent erhält keinen direkten Zugriff auf dein Gedächtnis, deine Schlüssel oder andere Quellen.
- Geänderte oder zurückgezogene Quellen, Abläufe und Zugänge halten alte Ergebnisse zurück. Wiederholte Anfragen starten keine doppelten Aufträge; ein Abbruch wartet auf das tatsächliche Ende der Arbeit.
- Die neue Mac-App prüft Einrichtung, Wiederholung und Rücknahme. Vor Sicherung und Update werden laufende lokale Prüfungen beendet. Ohne eingerichtete Werkzeuge bleibt Kingfisher normal nutzbar.
- Für die optionalen Werkzeuge wird auch die neue Mac-App benötigt; ein Backend-Update allein ersetzt eine ältere App-Hülle nicht. Die bestehenden lokalen Modelle, Cloud-Freigaben und der pausierte Großimport werden nicht umgestellt.

App mindestens: 1.0.36
