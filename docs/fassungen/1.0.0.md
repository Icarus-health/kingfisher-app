# Kingfisher 1.0.0

Die erste Fassung zum Herunterladen. Jeder Spiegelstrich wird ein Satz im Update-Angebot und auf der Download-Seite
(`scripts/release_seite.py`); der erste steht auf Heute im Hinweis. Kurz, in Alltagssprache, ein Satz je Neuerung.

- Kingfisher gibt es jetzt als App für den Mac zum Herunterladen.
- Neue Fassungen bietet Kingfisher dir selbst an, und vor jedem Update sichert es deine Daten.
- Einmal am Tag sieht Kingfisher nach, ob es eine neue Fassung gibt; ausschalten kannst du das unter „Kingfisher und du“.

App mindestens: 1.0.0
