# Kingfisher 1.0.39

Datum: 2026-11-02

- Gedächtnis: Ein fehlender Beleg wird als offener Nachweis erklärt, ohne zu behaupten, im Archiv gebe es keine Information. Hinweise auf noch ungeprüfte Quellen bleiben sichtbar.
- Fristen: Bedingte Zeitregeln bleiben als Belege erhalten. Ein fehlender notwendiger Zeitbezug wird weiter geklärt; andere Datumsfelder ersetzen ohne ausdrückliche Verknüpfung keine Frist.
- Mailbelege: Ein einzelner Umbruch innerhalb einer vollständig bekannten HTML-Entity lässt sich eindeutig auf den unveränderten Originaltext zurückführen. Mehrdeutige oder inhaltlich veränderte Zitate bleiben ausgeschlossen.
- Einordnung: Die KI erhält eine klare Unterscheidung zwischen benannten Vorhaben und Produkt-, App- oder Abonamen. Erwähnungen bleiben unbestätigte Hinweise.
- Lokale Auswahl: Kompaktere Anweisungen lassen mehr Platz für Originalbelege; Quellen-, Kontext-, Seiten- und Zeitgrenzen bleiben unverändert.

App mindestens: 1.0.36
