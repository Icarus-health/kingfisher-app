# Kingfisher 1.0.42

Datum: 2026-11-02

- Mistral kann ausdrücklich ausgewählte Mailpakete am EU-Endpunkt einordnen. Dafür wird Small 4 verwendet; deine Alltagsmodelle und der pausierte Großimport bleiben erhalten.
- Ein separates Kostenlimit startet bei 0 USD. Du siehst verbrauchte, reservierte und verbleibende Beträge. Ein geändertes Limit verlangt eine neue Paketvorschau; unklare Abrechnung stoppt weitere Aufrufe.
- Schlüssel speichern, Kostenstand ansehen und Vorschau erstellen senden keine Quellen. Erst die gesonderte Paketfreigabe erlaubt die Einordnung. Sie prüft weiterhin Originalbelege und den aktuellen Quellenstand.
- Die Paketansicht nennt den tatsächlichen Anbieter und führt zum passenden Einrichtungsbereich. Eingaben bleiben nach fehlgeschlagenem Speichern erhalten.
- Die getrennte künstliche Quellenprobe ist vorbereitet. Sie ersetzt keine Prüfung von Personen, Aufgaben und Fristen; ein vollständig verarbeitetes Paket allein gibt den Großimport nicht frei.
- Die neue Mac-App wählt bei Start und Update ausdrücklich den Hauptdienst. Das bereitet zusätzliche Module vor; noch wird kein solches Modul installiert oder aktiviert. Ein reines Backend-Update ersetzt eine ältere Mac-App-Hülle nicht.

App mindestens: 1.0.36
