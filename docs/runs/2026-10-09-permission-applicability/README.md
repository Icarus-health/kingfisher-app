## Fehler und Schutz

Im vorherigen echten Produktlauf verlor RQ20 „vor der Reinigung“: Die Quelle erlaubt ausschließlich ein trockenes Tuch **vor der Reinigung**, der freie Modellsatz machte daraus eine allgemeine Erlaubnis. Die neue gemeinsame Satzprüfung bindet erkannte zeitliche Einschränkungen an dieselbe normative Aussage. Zwei Inhaltsanker sind nötig; Kennungen und Modalwörter genügen nicht. Unabhängige Angaben wie das Lösungsmittelverbot bleiben erhalten. Erlaubte Alternativen können in getrennten Quellen stehen; ein Verbot darf einer Erlaubnis keine zeitliche Unterstützung verleihen. Koordinierte Teilsätze werden begrenzt getrennt, auch bei invertierter Wortstellung. Gespeicherte Antworten nutzen denselben Schutz. Keine Änderung an Originalen, Indizes, Modellfreigaben oder globaler Verneinungslogik.

Das ist ein notwendiger Wortlaut-/Anwendbarkeitsschutz, keine allgemeine Bedeutungsprüfung. Ereignis und optionales Adjektiv werden eng verglichen; „vor dem Reinigen“ kann gegenüber „vor der Reinigung“ auf Originalzitate zurückfallen. Beliebige Syntax, Beziehungen und Gegenstandsidentität werden nicht verstanden.
