# RQ06 negative recheck design review

**Verdict: proceed with the bounded design, with the guard conditions below.** The observed failure is localized: original mode already sends the source clauses as numbered, verbatim units and enforces “Eine Regel belegt nicht, dass ihre Voraussetzung erfüllt ist,” but `nichts_vorliegend` with no selected units exits `_urteilen` before any sentence checks. A single retry can address an abstention without changing evidence acquisition or the answer-generation contract.

- Keep both calls in original-selection mode: identical user JSON/context, numbered units, schema, provider, and output limits. Make the clarification in the system instruction only. It should say to inspect whether a unit directly answers the question, including an explicit source statement that a required status/approval is absent; a rule, prohibition, or prerequisite by itself proves neither fulfillment nor non-fulfillment. Never ask the model to infer a status or manufacture an answer.
- Retry only after a successfully parsed first response with `status == nichts_vorliegend` and an empty `originalstellen`. Do not retry `unklar`, malformed output, provider errors, or contradictory status/selection. This keeps the additional local-model latency bounded to one extra selector call in this narrow case. Existing `saetze_modell` timing accumulates repeated sections, so the retry is measurable without a new metric. Record real-device p50/p90 before asserting the latency target; a synthetic replay cannot establish latency.
- Parse the retry with the same strict `_original_lesen` and the same original ID map, then pass any selected units unchanged through `_urteilen` and all existing gates. If the retry again returns valid empty `nichts_vorliegend`, preserve unknown. If it returns `unklar`, malformed data, an invented/wrong unit, or raises, fail closed to quotes. Do not fall back to ordinary text mode or let a second response bypass `_zweites_tor`, paragraph completeness, negation, source completeness, or persistence validation.
- Do not expand or reconstruct the offered context on retry. `_originalstellen` deliberately omits hidden/partial units and rejects oversized clauses; a retry must not make those selectable. Preserve the original untrusted-source boundary and tool-call rejection.

The proposed tests cover the key regression if they use a scripted provider and assert the exact call count, unchanged schema/context/unit map, rendered verbatim paragraph plus refs, and that reopening after source withdrawal/invalidated refs returns citation mode. Add/retain cases for first-call `unklar` (no retry), final `nichts` (unknown, not a fabricated sentence), explicit negative evidence versus rule-only evidence, prompt-injection text, wrong/out-of-range unit, malformed/error second call, and a provider with only one scripted response. The last case should show a controlled quote fallback rather than an uncaught exception or accidental second attempt. Existing tests already exercise the downstream literal-condition, complete-paragraph, negation, and reopened-answer gates; reuse them rather than duplicating those checks.
