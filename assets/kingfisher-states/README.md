# Kingfisher State Assets

This directory contains the canonical visual state language for the Kingfisher bird.

## Required states

1. `observing` — perched, alert, calm
2. `active` — controlled flight / orchestration
3. `diving` — deep research / focused retrieval
4. `surfacing` — result or insight emerging
5. `clarity` — information fragments resolving into structure
6. `rest` — settled, low-energy, nothing urgent

## Approval policy

Assets placed here are not automatically approved. An approved asset must also be referenced from the design paper/change log and exported to the appropriate production format.

## Identity consistency

Every state must use the same canonical bird identity: anatomy, proportions, plumage pattern, colour character, eye/beak treatment, and illustration realism.

Do not independently prompt or regenerate a new bird per screen.
